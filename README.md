# Дизайн-навыки для Codex

| Навык | Для чего |
| --- | --- |
| `$impeccable` | Ревью и доработка дизайна интерфейсов |
| `$design-taste-frontend` | Визуальное направление для сайтов и интерфейсов |
| `$animate` | Анимации и переходы в интерфейсах |
| `$canvas-design` | Плакаты, обложки и статичные макеты |
| `$algorithmic-art` | Генеративные паттерны, текстуры и серии визуалов |

Подключи этот репозиторий к облачной среде Codex «Дизайн». В чате настройки среды попроси запустить из корня репозитория:

```bash
bash install.sh
```

Установщик скачивает закреплённые версии из репозиториев авторов и копирует папки навыков в `~/.agents/skills`. Уже установленные навыки пропускаются. Для установки нужны Git, Bash и доступ к GitHub.

После установки опубликуй конфигурацию среды и открой новую задачу в ней, чтобы проверить вызов навыков по их именам.
